# Product

## Register

product

## Users

技術決策者、開源探勘者與工程團隊成員，需要即時掌握 GitHub 熱門專案的動態與趨勢。

## Product Purpose

Dora GitHub Trending Dashboard 是一套自動化監控 GitHub 熱門專案的工具。透過每日 20:00 自動爬取 GitHub Trending 資料，存入 Supabase 資料庫，並以儀表板呈現每日、每週、每月熱門專案的星數變化。讓技術決策團隊能快速掌握各語言、各領域的熱門專案趨勢，作為技術選型、專案架構與生態投資的參考依據。

## Brand Personality

Professional, Analytical, Insightful

## Anti-references

- Generic SaaS landing pages with hero metrics
- Corporate fintech blue-and-white themes
- Overly decorative designs that prioritize aesthetics over data clarity

## Design Principles

1. **Data-first, decoration-second** — Every visual element must serve the data. Charts, tables, and metrics come first; embellishments only if they aid comprehension.
2. **Clear hierarchy of insight** — Daily trends → Weekly trends → Monthly trends. Users should be able to drill down from immediate to long-term patterns.
3. **Dark mode native** — The dashboard is designed for extended viewing sessions; dark mode reduces eye strain and matches the GitHub aesthetic.

## Accessibility & Inclusion

Support for reduced motion preferences. High contrast ratios for data visualization. Clear visual distinction between chart elements and data labels.
